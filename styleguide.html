Exploration PWA design system

shadcn/ui Nova tokens (neutral base) rebuilt as plain CSS, so the app keeps running offline with no build step. Token names match shadcn, so a React port is a copy, not a redesign. Atomic Design: tokens → atoms → molecules → organisms → templates → screens.

Data viz

Fixed categorical order, never cycled. Charts read --chart-N, so they re-color in dark mode.

Do and don't

Do
Use var(--muted-foreground) for secondary text. Pair status color with an icon and a label. Use .btn.primary once per card.
Don't
Write raw hex in a component. Use red/green alone to signal pass/fail. Add a z-index outside the --z-* scale.
